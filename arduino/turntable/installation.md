# 턴테이블 설치 · 재조립 체크리스트

전시 현장에서 분해했다 다시 조립할 때 보는 문서. 펌웨어는 같은 폴더의 `turntable.ino`.
2026-10-15 기준 구성: **Uno R3 + 17HS3430(NEMA17, 직결) + TMC2208 + TCRT5000 + 12V**.

> ⚠️ 2026-10-14 시험 중 Uno의 ATmega328이 탔다(원인 미확인 — Vref 재다가 12V에 닿았을 가능성).
> 아래 **[전원 넣기 전 점검](#4-전원-넣기-전-점검)**은 매번 빠짐없이.

## 2. 회로

### TMC2208 핀 (모듈마다 표기가 조금 다름 — `B2`/`2B`/`OB2`, `VDD`/`VIO`. 뒷면 글씨로 확인)

```
            ┌───────────────┐
  EN    ──  │ ●           ● │  ── VM     ← 12V (+)  + 커패시터 긴 다리
  MS1   ──  │ ●           ● │  ── GND    ← 12V (−)  + 커패시터 짧은 다리(흰 띠)
  MS2   ──  │ ●   [가변   ● │  ── B2     ← 파랑
  PDN/RX ─  │ ●   저항]   ● │  ── B1     ← 빨강
  UART/TX ─ │ ●           ● │  ── A1     ← 초록
  CLK   ──  │ ●           ● │  ── A2     ← 검정
  STEP  ──  │ ●           ● │  ── VDD    ← Uno 5V
  DIR   ──  │ ●           ● │  ── GND    ← Uno GND
            └───────────────┘
```

### 연결표

| 드라이버 / 센서 | 연결 |
| --- | --- |
| VM | 12V (+) |
| GND (VM 옆) | 12V (−) |
| 커패시터 | 긴 다리 → 12V (+) 줄, 짧은 다리(흰 띠) → 12V (−) 줄 |
| B2 · B1 · A1 · A2 | 파랑 · 빨강 · 초록 · 검정 |
| VDD | Uno **5V** |
| GND (VDD 옆) | Uno **GND** |
| STEP | Uno **D3** |
| DIR | Uno **D4** |
| EN | Uno **D5** |
| MS1, MS2, PDN/RX, UART/TX, CLK | **비움** |
| TCRT5000 VCC / GND / DO | Uno 5V / GND / **D7** |

- 모터 쌍(검·초 / 빨·파)만 지키면 쌍 안의 순서는 바뀌어도 된다 — 회전 방향만 반대가 된다(펌웨어 `DIR_INVERT`).
- 12V(−)와 Uno GND는 드라이버 안에서 이어지므로 따로 묶지 않는다.
- 드라이버는 **브레드보드에 꽂지 않고** 핀에 암 점퍼만 꽂아 쓴다(지금 방식). 꽂는다면 반드시 가운데 홈을 걸쳐서 —
  같은 줄에 들어간 핀끼리 이어져서 VM(12V)이 VDD(5V)로 넘어간다.
- 커패시터와 12V 선은 브레드보드 가운데 홈 **한쪽**에만, 가로 5칸이 한 줄: `12V(+) · 커패시터(+) · VM 선`이 한 줄,
  `12V(−) · 커패시터(−) · GND 선`이 다른 한 줄.

### Vref (전류 설정)

**12V로 쓰는 한 재지 않아도 된다** — 모터 저항이 전류를 12V ÷ 30Ω = 0.4A(= 정격)에서 막는다.
가변저항은 **중간에서 시계 방향으로 조금 더**. 판이 힘없이 버벅이면 조금 더 올린다.

- ⚠️ **24V로 바꾸면 반드시 0.5~0.55V로 맞출 것.**
- 잴 땐 Uno A0를 쓰지 말 것(칩이 탄 원인 후보). 꼭 Uno로 잰다면 A0 앞에 **10kΩ 저항**을 끼우고 악어 클립으로.

## 3. 기구 조립

도면은 `make_plates.py`가 만든다(`python3 make_plates.py`). 수치를 바꿀 땐 스크립트 위쪽 상수만 고쳐서 다시 만든다.

### 쌓는 순서 (밑판 윗면 기준 높이, 5t 아크릴 기준)

```
 20.9 ┬─ 윗판 아랫면 ───────── 커플러 플랜지(3)가 여기 붙음. 축 끝은 1.9mm 밑에서 끝남 → 윗판 축 구멍 없음
      │  실리콘 받침 6 (붙이는 범폰) ← 안쪽 링에만. 윗판이 바깥 링(고정)에서 이만큼 뜬다
 14.9 ┼─ 레이지수잔 윗면
      │  레이지수잔 8.5          커플러 허브(10) — 축이 11.1mm 물림
  7.9 │                          허브 끝
  6.4 ┼─ 레이지수잔 아랫면 ───── 바깥 링만 M4 너트(2개씩)에 얹힘, 안쪽 링은 밑판에서 6.4 뜸
      │  M4 너트 2 × 4
  0   ┴─ 밑판 윗면 ───────────── 센서는 M3 스페이서(≈8)로 띄워 윗판과 3~5mm
 -5 ── 밑판 아랫면 ───────────── 모터 장착면(보스 Ø22가 구멍에 들어감), 몸통 34mm가 아래로
```

**두께가 바뀌면** `make_plates.py`의 `BASE_T`·`SUPPORT_L`·`LS_T`·`FOOT_H`를 바꿔 다시 만든다 — 스크립트가 허브가
밑판에 닿거나, 축이 덜 물리거나, 축이 윗판 위로 나오면 멈춘다. 실리콘 받침 윗면과 커플러 플랜지 윗면이 같은 높이여야
판이 안 기운다 — 높이는 아래 5번처럼 자를 대고 맞추면 받침 높이를 몰라도 된다.

1. **밑판 → 프레임** — 도면 아래 변(삼각형)이 **관람객 쪽(경사면 덮개 쪽)**. 프레임 위 3030 프로파일에 M6.
   (구멍은 프로파일 중심선 = 바깥에서 15mm 가정 — 프레임 실측 후 자를 것)
   경사면 덮개를 **먼저** 걸고, 그 위 날개(1.5t, 깊이 30)를 앞 프로파일 위에 깐 다음 밑판을 얹는다 —
   밑판 아랫면 앞 변의 1.5 단차에 날개가 들어간다. 앞줄 M6 3개는 밑판·날개·프로파일을 같이 조인다
   (볼트 길이: 남은 밑판 3.5 + 날개 1.5 + 와셔 + 너트 물림). 뒷줄은 밑판 5t만.
2. **모터** — 밑판 **아래**에서 보스를 Ø23 구멍에 끼우고 M3×10 4개(모터 나사 깊이 4.5 이상, 5t + 4~5). 모터선은
   어느 쪽으로 나와도 된다.
3. **센서 TCRT5000** — 밑판 **위**, 새긴 사각형 자리에 눕힌다(센서 머리 = + 표시 = 반지름 42, 보드는 접선 방향 —
   우드락 시제품과 같다). 센서 머리 양옆 M3 구멍 2개에 M3 스페이서를 세워 고정한다.
   핀 헤더가 ㄱ자로 옆을 향한다. 커넥터 끝이 반지름 ≈65(레이지수잔 안쪽 72.5)라 여유가 있지만,
   선은 커넥터에서 **중심 쪽으로** 꺾어 커넥터 옆 배선 구멍으로 내린다.
   - **센서 윗면과 윗판 아랫면 사이 3~5mm** — 스페이서 길이로 맞춘다(대략 5~6mm). TCRT5000은 가까울수록 또렷하다
     (예전 우드락 판은 거의 18mm 떨어져 있어서 테이프 폭이 흐릿하게 재졌다).
   - 모듈 감도 가변저항: 흰 면에서 LED 꺼짐, 테이프에서 켜짐이 되게.
   - 보드 치수는 판매 사진을 픽셀로 잰 **추정값**이다: 41.9×10.2, 구멍 Ø3.5 두 개가 센서 머리 양옆 ±5.75
     (간격 11.5, 보드 가운데 줄), 센서 머리는 짧은 끝에서 8.9(시제품 사진으로도 맞음). 오차를 생각해 구멍을 보드 방향 ±0.75 장공으로 냈다.
     실물을 재서 다르면 `SENSOR_*` 상수를 고쳐 다시 만든다.
4. **레이지수잔** — 바깥 링 접시 자리 면이 **위**. 접시머리 M4×25를 위에서 바깥 링 → 띄우기 너트 2개 → 밑판 순서로
   꽂고 밑판 밑에서 너트로 조인다(8.5 + 6.4 + 5 + 3.2 = 23.1, 끝이 2mm쯤 나온다).
   너트 1개만 띄우면(M4×20) 축 끝이 윗판으로 1.3 들어가 윗판 가운데 구멍이 다시 필요하다 — `SUPPORT_L = 3.2`.
   띄우기 너트는 링 밑에 먼저 한 바퀴 돌려 붙여 두면 꽂기 쉽다.
   **둥근 머리는 안 된다** — 링 윗면 위로 나와 윗판에 긁힌다. 안쪽 링 구멍엔 실리콘 받침을 **위로** 다시 끼운다.
   안쪽 링을 손으로 돌려 밑판에 안 끌리는지 본다.
5. **커플러 → 축** (윗판보다 **먼저**) — 윗판을 얹으면 허브 고정볼트가 레이지수잔 링 뒤에 숨어서 렌치가 안 들어간다.
   - 플랜지 밑면 구멍 4개에 M3 너트를 순간접착제로 미리 붙여 둔다(윗판을 얹은 뒤엔 너트를 못 잡는다).
     너트 한 변(평면)이 허브 쪽을 보게 — 허브 면까지 0.25밖에 안 남아 모서리를 향하면 허브에 걸린다.
   - 허브를 축에 끼우고, 실리콘 받침 위에 곧은 자를 걸쳐 **플랜지 윗면이 자에 닿을 때까지** 올린다 → 받침과 같은 높이.
   - 고정볼트 M4 2개를 **D컷 평면 쪽**에 조인다(위에서 L렌치 짧은 쪽을 옆으로).
6. **윗판 올리기** — 윗판을 받침 위에 얹고 0번 삼각형을 밑판 삼각형(관람객 쪽)에 맞춘 뒤, M3×10을 위에서 플랜지
   너트에 조인다. 윗판과 레이지수잔은 고정하지 않는다 — 커플러가 중심·높이·
   회전을 다 잡고, 베어링은 받치기만 한다(둘 다 박으면 중심이 조금만 어긋나도 비틀려 뻑뻑해진다).
7. **판 중심 확인** — 판을 손으로 천천히 돌리며 가장자리를 고정된 것과 비교. 가까워졌다 멀어졌다 하면 치우친 것.
   2026-10-15 우드락 판을 다시 끼웠더니 테이프 폭·위치가 몇 °씩 달라졌다 — 이게 원인으로 보인다.
8. **테이프 (윗판 아랫면)** — 반지름 42, 90° 간격 4개. 0번(mycelium, 삼각형 쪽)만 넓게, 나머지 1cm.
   - 넓은 것은 **60°(반지름 42에서 호 약 4.4cm)** — 좁은 것(1cm ≈ 14°)과 차이가 커야 0번을 구분한다(기준 5°).
     늘릴 땐 **가운데 기준으로 양쪽에 똑같이**(0점이 안 바뀌게). 70° 넘게는 하지 말 것 — 옆 테이프와 너무 가까워진다.
   - `top_plate.svg` 아랫면 눈금(반지름 53~59)에 맞춰 붙인다. 테이프는 반지름 34~50을 덮게.
   - 순서: 판이 + 방향으로 돌 때 0 mycelium → 1 signal → 2 dandelion → 3 sora (dial.js 구멍 순서와 같음).
   - 테이프 간격이 정확히 90°가 아니어도 된다 — 호밍 때 어긋남(`offsets`)을 재서 보정한다.

### 윗판 도면 `top_plate.svg` (레이저 1:1, Ø300)

| 색 | 가공 | 내용 |
| --- | --- | --- |
| 빨강 `#FF0000` | 자르기 | 바깥 Ø300, 커플러 구멍 4-Ø3.4 (지름 21 원 위, 0·90·180·270°) |
| 파랑 `#0000FF` | 윗면 새기기 | 사물 자리 눈금 4개(가장자리), 0번 삼각형, 커플러 플랜지 Ø28 원 |
| 초록 `#00FF00` | 아랫면 새기기 (선택) | 레이지수잔 Ø202·Ø145 원, 테이프 자리 눈금 |

- **0° = 위 = 센서 쪽.** 호밍이 끝나면 0번(삼각형) 사물이 센서 쪽 = 관람객 쪽에 온다.
- 아랫면 표시는 세로축 대칭이라 업체가 판을 **좌우로** 뒤집어 새기면 된다. 양면 가공이 안 되면 초록은 빼고, 종이에
  인쇄한 원을 대고 표시해도 된다. 테이프 눈금은 센서 띠(반지름 34~50) **밖**에 있다 — 새김선을 센서가 테이프로 읽지 않게.
- 1~3번 이름(signal·dandelion·sora)은 새기지 않았다 — 어느 쪽이 1번인지는 모터 배선(`DIR_INVERT`)에 따라 바뀐다.
  조립 후 `1`을 보내 센서 쪽에 오는 자리가 signal.
- **⚠️ 아크릴 색: 투명은 안 된다.** TCRT5000은 흰 면에 반사된 적외선을 본다 — 투명이면 빛이 통과해 전부 "검정"으로
  읽힌다. **흰색 불투명**으로 하거나, 투명이면 아랫면 반지름 40~60 띠에 흰 종이·흰 시트를 붙이고 그 위에 테이프.

### 밑판 도면 `base_plate.svg` (레이저 1:1, 밑판 360×300)

| 색 | 가공 | 내용 |
| --- | --- | --- |
| 빨강 `#FF0000` | 자르기 | 밑판 바깥, 프레임 M6 구멍 6개, 모터 보스 Ø23 + M3 4개(31 간격), 센서 M3 장공 2개, 센서 배선 구멍, 레이지수잔 M4 4개(PCD 187, 45° 자리) |
| 파랑 `#0000FF` | 윗면 새기기 | 레이지수잔 Ø202·두 링 사이 원, 띄우기 너트 자리, 센서 보드 자리 + 센서 머리 표시, 모터 몸통 윤곽(참고), 관람객 쪽 삼각형 |
| 자홍 `#FF00FF` 채움 | 아랫면 파기 1.5 | 앞 변 전체 폭 × 31 — 경사면 덮개 위 날개 자리(남는 두께 3.5) |

- 밑판 색은 상관없다(센서는 윗판을 본다).
- 단차는 레이저 래스터로 깊이를 내면 바닥이 고르지 않을 수 있다 — 업체에 "깊이 1.5 포켓"으로 따로 말하고,
  가능하면 CNC로. 날개가 R15로 꺾이며 내려가므로 모서리 쪽 0~6mm는 날개에 안 닿아도 된다.
  날개 길이·두께가 바뀌면 `COVER_WING`·`COVER_T`(= `housing/cover/make_cover.py`의 `WING`·`T`)를 같이 고친다.
- 밑판 크기와 M6 구멍은 하우징 프레임(`housing/structure_frame.pdf`, 위 360×300, 3030)을 보고 잡은 **가정**이다 —
  턴테이블이 프레임 위가 아닌 다른 곳에 놓이면 `BASE_W`·`BASE_H`·`FRAME_*`을 고친다.
- 센서 배선 구멍은 모터 몸통(42.3 □) 밖에 있다 — 센서를 반지름 방향으로 세우면 커넥터가 축·커플러나 레이지수잔 안쪽에
  걸려서 접선으로 눕혔다. 커넥터·배선 구멍이 고리에 닿는 조합이면 `make_plates.py`가 멈춘다 —
  그땐 `SENSOR_TILT`(보드를 중심 쪽으로 돌리는 각)를 10° 이상 준다.

## 4. 전원 넣기 전 점검

- [ ] **12V 선(빨·파 / VM·GND 줄)이 Uno의 어떤 핀에도, 5V 줄에도 닿지 않는다**
- [ ] 드라이버 방향: VM·모터선이 한쪽 줄, EN·STEP·DIR이 반대쪽 줄
- [ ] VM = 12V, VDD = 5V (헷갈리면 칩이 탄다)
- [ ] Uno 쪽 빨강이 **5V**(3.3V·Vin 아님), 검정이 GND
- [ ] 커패시터 긴 다리가 12V(+)
- [ ] DC 잭 단자대: 빨강 = +, 파랑 = − (단자대 표시 확인)
- [ ] 모터 쌍: 검·초가 A1·A2, 빨·파가 B1·B2

### 켜고 끄는 순서

- **켤 때: USB → 12V.** (Uno가 먼저 EN을 잡아야 드라이버가 엉뚱하게 안 움직인다)
- **끌 때: 12V → USB.**
- **모터선은 둘 다 뽑힌 상태에서만** 꽂고 뺀다 — 켜진 채로 뽑으면 드라이버가 탄다.
- 소리·냄새·열이 이상하면 **12V부터** 뽑는다.
- USB만 꽂았는데 Uno가 뜨거우면 즉시 뽑는다 — 선을 다 빼고 보드만 꽂아도 뜨거우면 ATmega328 교체.

## 5. 펌웨어 · 시험

### 업로드

Arduino IDE에서 `turntable.ino` → 보드 Arduino Uno. 라이브러리 **AccelStepper** 필요.
상단 `#define NEMA17 1` (0이면 예전 28BYJ-48 + ULN2003 설정).

### 시리얼 명령 (115200, 줄바꿈)

| 보냄 | 동작 |
| --- | --- |
| `0`~`3` 또는 `mycelium` `signal` `dandelion` `sora` | 그 사물을 앞으로 → `arrived <이름>` |
| `h` | 다시 호밍 |
| `g` | 멈출 자리 전환: `grid 1` = 정확한 90° 자리(기본) / `grid 0` = 테이프 가운데. 전원 끄면 기본으로 |

### 켜자마자 (호밍, 약 20초 — 한 바퀴 돌며 테이프 4개를 다 잰다)

```
mark 79          ← 테이프 폭(스텝, 1600스텝 = 1바퀴, 4.4스텝 ≈ 1°)
mark 77
mark 126         ← 하나가 눈에 띄게 넓어야 한다
mark 89
wide_min 107     ← 넓은/좁은 기준(그때 잰 값의 중간)
offsets 0 13 1 -13   ← 테이프가 정확한 90° 자리에서 어긋난 정도(mycelium·signal·dandelion·sora)
homed
```

### 이동 시험 — `1` `2` `3` `0` 차례로

```
mark 89
fix 2            ← ±5 이내면 정상
arrived signal
```

## 6. 아크릴 부품으로 바꾼 뒤 보정

판·센서 높이·축 연결이 바뀌면 테이프 폭과 `offsets`가 다 달라진다. 값은 **최종 부품으로 조립한 뒤** 맞춘다.

1. **호밍 통과** — 넓은 것과 두 번째로 넓은 것의 `mark` 차이가 **22 이상**(펌웨어 `WIDE_GAP` = 5°). 30 넘게 여유가 있으면 좋다.
2. **판을 뺐다 다시 끼우고 `h`** — `mark`·`offsets`가 크게(10 이상) 바뀌면 판 중심이 안 맞는 것(3-4 참고).
3. **`1` `2` `3` `0` → `fix`가 모두 ±5 이내.**
4. **`g`로 두 방식 비교** — 같은 번호를 다시 보내면 그 자리에서 90° 자리 ↔ 테이프 가운데를 오간다.
   사물이 정면에 더 잘 서는 쪽으로. 테이프 가운데가 낫다면 펌웨어 `snapGrid = false`로 바꿔 업로드.
5. **20회 반복** — 사물(최대 2kg)을 올린 채 `0`~`3`을 섞어 20번. `lost`/`wrong_mark` 없이, 출렁임 없이.
6. **30분 켜 두고** 모터·드라이버를 만져 본다. 따뜻한 정도면 정상.

### 조정할 수 있는 값 (`turntable.ino` 위쪽 `#if NEMA17` 블록)

| 값 | 기본 | 언제 바꾸나 |
| --- | --- | --- |
| `DIR_INVERT` | false | 1→2→3이 거꾸로 돌 때 true |
| `FAST` | 90°/초 | 전환 속도 |
| `ACCEL` | 90°/초² | 멈출 때 판이 출렁이면 줄인다(예: 45) |
| `SEEK` | 20°/초 | 테이프 찾는 속도. 빠르면 폭 측정이 거칠어진다 |
| `APPROACH` | 15° | 목표 몇 ° 앞부터 천천히 찾을지 |
| `HOLD` | false | true면 멈춰서도 판을 붙잡지만 "지잉" 소리가 크다 |
| `snapGrid` | true | 위 4번 |

## 7. 문제 해결

| 증상 | 원인 · 조치 |
| --- | --- |
| `home_fail no_plate` | 센서 아래가 계속 검다 — 판이 없거나, 센서가 너무 멀거나, **판이 투명**하다. 센서 모듈 LED가 흰 면/테이프에서 바뀌는지 보고 모듈 가변저항(감도) 조정 |
| `home_fail no_mark` | 반 바퀴 안에 테이프를 못 찾음 — 테이프가 센서 원(반지름 42)을 벗어났거나, 모터가 안 돎 |
| `home_fail no_wide` | 넓은 테이프가 두 번째보다 5° 이상 넓지 않음 — `mark` 값 확인. 넓은 테이프를 60°까지 늘리거나 센서 높이 확인 |
| `lost` / `wrong_mark` | 이동 중 테이프를 놓쳤거나 엉뚱한 테이프 — 자동으로 재호밍 후 한 번 재시도한다. 반복되면 축이 헛도는지(펜 줄) 확인 |
| `fix`가 크다 | 축이 헛돈다(커플러 고정볼트가 D컷 평면에 안 닿음) 또는 판이 치우쳐 돈다 |
| 모터가 "웅" 소리만 내고 떤다 | 모터 쌍이 틀림 — 전원 다 끄고 A1·B1에 꽂힌 선을 맞바꿈 |
| 아무 반응 없음 | 12V가 안 들어감 / EN·STEP·DIR 배선 / 단자대 극성 |
| 힘이 없어 손으로 쉽게 멈춤 | 드라이버 가변저항을 시계 방향으로 조금 더 |
| 멈출 때 판이 출렁임 | `ACCEL`을 낮춘다. 그래도 안 되면 판 테두리 GT2 벨트 감속 |
| 정지 중 소음 | `HOLD = false`인지 확인 |
| 멈춰 있을 때 판이 손에 돈다 | `HOLD = false`라서 정상. 다음 이동 때 센서가 바로잡고, 45° 넘게 밀리면 재호밍 |

## 8. 전시 화면과 연결

- `output.html`이 Web Serial로 턴테이블을 직접 연다. **처음 한 번만** 오른쪽 위 `panel ○ table ○` 버튼(또는 Alt+S)으로
  포트를 고른다. 그 뒤로는 새로고침·USB 재연결 때 저절로 붙는다.
- **Arduino IDE 시리얼 모니터는 닫을 것** — 한 포트는 한 프로그램만 연다.
- 포트가 열리면 Uno가 리셋돼 **호밍부터**(약 20초) 한다. `homed`를 받으면 페이지가 지금 receiver를 다시 보낸다.
  화면은 판 도착을 기다리지 않는다.
- `home_fail` / `lost` / `wrong_mark`는 페이지가 `reportError`로 띄운다.
