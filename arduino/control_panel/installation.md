# 컨트롤 패널 설치 · 재조립 체크리스트

전시 현장에서 분해했다 다시 조립할 때, 선이 빠졌을 때 보는 문서. 펌웨어는 같은 폴더의 `control_panel.ino`.
2026-11-09 기준 구성: **Uno R4 WiFi + 12V 어댑터(아두이노 DC 잭) + PC817 4채널 절연 모듈 + ULN2003 보드(버튼 조명 제어) + WAGO + 브레드보드 2장**.

> 배선도: `wiring.png` (가변저항까지 들어간 완성본 — 추가 예정)

> ⚠️ **12V(VIN)가 아두이노 D핀·A핀·5V 핀에 닿으면 보드가 탄다.** 12V는 빨강, 5V는 주황, GND는 검정 — 색 규칙을 지킬 것.

## 1. 부품

| 부품 | 위치(패널) | 비고 |
| --- | --- | --- |
| Arduino Uno R4 WiFi | 판 뒷면 | USB = 통신(Web Serial) + 로직 전원, DC 잭 = 12V |
| 12V 1A 어댑터 | 아두이노 DC 잭 | **VIN 핀에 12V가 그대로 나온다** — 버튼 조명 전원. DC 잭 변환 단자대는 안 씀 |
| 메탈 버튼 5선 × 3 (날씨·밥·안녕) | 오른쪽 세로 줄 | 조명 12–24V. 스위치와 조명이 **분리**된 구조(C / NC / NO / 1 / 2) |
| 메탈 래칭 버튼 3선 × 2 (농담·질문) | 아래 가운데 (😊 / ?) | 조명 12–24V. 단자 N / NO / C — **N은 NC가 아니라 LED −**. 잠그면 C→NO로 12V가 나가며 링이 켜진다 |
| 파란 사각 아케이드 버튼 (보내기) | 오른쪽 아래 | 조명 5–12V. 마이크로스위치(COM / NO / NC) + 램프 소켓(+ / −)이 **분리** |
| MTS202 토글 + 패널 LED (INVERSE = hi↔bye) | 오른쪽 위 | 토글은 스위치 2개(3단자 × 2줄). LED 6–12V |
| 가변저항 노브 (크기) | 왼쪽 아래 | 3다리 |
| 슬라이드 가변저항 B10K × 2 (자간·행간) | 아래 가운데 | **2연(다리 6개: 한쪽 4, 반대쪽 2)** — 한 세트(3다리)만 쓴다 |
| "817 Module 4 Channel Isolation" | 판 뒷면 | 입력 쪽 저항(302 = 3kΩ) 내장 → **12V를 그대로 넣는다**. 노란 점퍼는 꽂힌 그대로 |
| ULN2003 드라이버 보드 (턴테이블 28BYJ-48 시절 것) | 판 뒷면 | 날씨·밥·안녕·보내기 조명의 LED −를 아두이노가 끊었다 붙였다 한다 — 평소 켜짐, 누르는 동안 꺼짐 |
| WAGO × 4 (12V 2개, GND 2개) + 5V용 1개 | 판 뒷면 | 한 칸에 전선 **한 가닥**. 칸이 모자라면 WAGO끼리 짧은 선으로 잇는다 |
| 브레드보드 2장 | 판 뒷면 | **레일이 가운데(30번 근처)에서 끊겨 있다** — 쓰는 레일은 전부 왼쪽 반 |

**예비로 챙길 것:** 점퍼선, 수축튜브, 절연테이프, WAGO 몇 개, 멀티미터.

## 2. 전원 구조

전기는 세 갈래이고 GND는 전부 하나다.

```
12V 어댑터 ─▶ 아두이노 DC 잭
                 VIN ── 빨강 ──▶ 12V 줄 (브레드보드1 아래 빨간 레일 왼쪽 반 + 12V WAGO 2개)
                 GND ── 검정 ──▶ GND 줄 (브레드보드2 위 파란 레일 왼쪽 반 + GND WAGO 2개 + 브레드보드1 위 파란 레일)
                 5V  ── 주황 ──▶ 5V WAGO (가변저항 3개 전용 — 12V 레일 근처에 두지 않는다)
```

- **12V 줄**: 버튼 조명 +, 농담·질문 C, 아케이드 램프 +, INVERSE 토글 2번 줄 가운데, ULN2003 보드 +
- **ULN2003 출력**: 날씨·밥·안녕·보내기 조명 − (GND 줄이 아니다 — 7절)
- **GND 줄**: 버튼 C / COM, 농담·질문 N, ULN2003 보드 −, 모듈 G 4개, INVERSE 토글 1번 줄 가운데, INVERSE LED −, 가변저항 한쪽 끝
- **5V 줄**: 가변저항 반대쪽 끝 3개뿐

### 어댑터를 빼면

| 부품 | USB만 | USB + 12V 어댑터 |
| --- | --- | --- |
| 날씨·밥·안녕·보내기 신호 | ✅ | ✅ |
| INVERSE 토글 신호 | ✅ | ✅ |
| 노브·슬라이더 | ✅ | ✅ |
| **농담·질문 신호** | ❌ (12V가 포토커플러를 켜야 신호가 생긴다) | ✅ |
| 버튼 조명·INVERSE LED | ❌ | ✅ |

**전시 중엔 어댑터를 항상 꽂아 둔다.** 농담·질문만 안 먹으면 어댑터부터 볼 것.

## 3. 연결표

| 부품 | 스위치 → 아두이노 | 조명 | 시리얼 |
| --- | --- | --- | --- |
| 안녕 (오른쪽 맨 위) | NO → **D4**, C → GND | + → 12V, − → ULN OUT3 (← **D11**) | `btn hello` |
| 날씨 (오른쪽 가운데) | NO → **D3**, C → GND | + → 12V, − → ULN OUT2 (← **D10**) | `btn weather` |
| 밥 (오른쪽 맨 아래) | NO → **D2**, C → GND | + → 12V, − → ULN OUT1 (← **D9**) | `btn meal` |
| 보내기 (아케이드) | 마이크로스위치 NO → **D5**, COM → GND | 램프 + → 12V, − → ULN OUT4 (← **D12**) | `btn send` |
| 농담 😊 | NO → 모듈 **IN1** → **V1 → D6** | C → 12V, N → GND (잠그면 켜짐) | `tog joke 1/0` |
| 질문 ? | NO → 모듈 **IN2** → **V2 → D7** | 〃 | `tog question 1/0` |
| INVERSE 토글 | 1번 줄: 가운데 → GND, 켜짐 단자 → **D8** | 2번 줄: 가운데 → 12V, 켜짐 단자 → LED +, LED − → GND | `tog bye 1/0` |
| 크기 노브 | 와이퍼 → **A0** | 양 끝 → 5V · GND | `knob size 0~1` |
| 자간 슬라이더 (위) | 와이퍼 → **A1** | 양 끝 → 5V · GND | `knob spacing 0~1` |
| 행간 슬라이더 (아래) | 와이퍼 → **A2** | 양 끝 → 5V · GND | `knob leading 0~1` |

> 날씨·밥은 처음엔 D2 = 날씨였는데 실물 배선이 반대라 **펌웨어 쪽 핀을 바꿨다**(2026-11-09). 선이 아니라 `control_panel.ino`의 `sws[]`가 기준.

### 버튼 커넥터 전선 색 (2026-11-09 배선 기준)

| 버튼 | 전선 → 단자 → 연결 |
| --- | --- |
| 날씨·밥·안녕 (5선, 파란 커넥터) | **초록** = LED + → 12V WAGO / **노랑·검정** = C, LED − → 원래 둘 다 GND WAGO였다. 조명 제어 뒤로는 그중 **LED −(버튼의 `1`/`2` 중 + 아닌 쪽)만 ULN 출력으로** 옮긴다 / **파랑** = NO → D핀 / **빨강** = NC → 연결 안 함(끝 절연) |
| 농담·질문 (3선, 빨간 커넥터) | **파랑** = C → 12V WAGO / **빨강** = NO → 모듈 IN / **검정** = N(LED −) → GND |

색은 제품마다 다르다 — 커넥터를 새로 끼웠으면 커넥터를 빼서 어느 색이 어느 단자 자리인지 다시 볼 것.

### 포토커플러 모듈 (농담·질문 전용)

```
  왼쪽 = 12V 쪽                 오른쪽 = 아두이노 쪽
  IN1 ← 농담 NO                  V1 → D6
  G   → GND   ★                  G  → GND
  IN2 ← 질문 NO                  V2 → D7
  G   → GND   ★                  G  → GND
  (3·4번 채널 예비)
```

★ **입력 쪽 G를 빼먹기 쉽다.** 비어 있으면 12V가 들어와도 안의 LED에 전류가 안 흘러 아무 반응이 없다(2026-11-09 처음 안 되던 원인). 신호가 들어오면 모듈의 작은 빨간 LED가 켜진다.

농담·질문 NO를 **아두이노에 바로 꽂으면 안 된다** — 잠기면 NO에 12V가 나온다.

## 4. 단자 찾기 (멀티미터)

프로브: 검정 → **COM**, 빨강 → **VΩ**. **10A 구멍엔 꽂지 않는다.**

### 스위치 C / NO — 🔊 도통 모드, 전원 뺀 상태
- 두 단자에 대고 **누를(잠글) 때만 삐** → C와 NO
- **안 누를 때 삐, 누르면 조용** → C와 NC
- 두 조합에 공통인 단자가 C(COM)

### INVERSE 토글 (MTS202)
- 3단자 × 2줄, **각 줄 가운데가 공통**. 레버를 젖히면 가운데가 **반대쪽 끝**과 붙는다
- 레버를 INVERSE(켜짐)로 두고 가운데와 삐 하는 끝 = "켜짐 단자". 두 줄 다 표시
- 납땜 후 **1번 줄과 2번 줄 사이에 소리가 안 나는지** 꼭 확인 — 납이 번지면 12V가 D8로 간다
- 시리얼이 반대(켰는데 0)면 D8 선을 1번 줄 반대쪽 끝으로

### LED 극성
- 표시(+, 빨간 점, 빨간 선, 긴 다리)가 있으면 그게 +
- 없으면 다이오드 모드(▶|): 반응하는 방향에서 빨간 프로브 쪽이 +. 내장 저항 때문에 반응이 없을 수 있다
- 그래도 모르면 12V·GND에 점퍼로 **잠깐** 대 보고, 켜질 때 12V 쪽이 +. 안 켜지면 반대로

### 가변저항 와이퍼 — Ω 모드(20k), 전원 뺀 상태
- **밀거나 돌려도 값이 그대로(B10K면 약 10k)인 쌍 = 양 끝**, 값이 0 ↔ 10k로 변하는 다리 = 와이퍼
- 슬라이더는 **2연(다리 6개)** — 10k 쌍이 두 개 나온다. 그중 하나와 그 쌍에 대해 변하는 와이퍼, 이렇게 **같은 세트 3다리**만 쓴다. 다른 세트끼리 대 보면 OL. 남는 3다리는 연결 안 함
- 방향이 반대면 **양 끝 두 선(5V·GND)만** 바꾼다

### 전압 확인 — V⎓ (20V), 전원 켠 상태
- 프로브 끝은 브레드보드의 **같은 줄 빈 구멍**에 꽂아 잰다. 아두이노 헤더에 직접 대면 옆 핀과 합선될 수 있다
- 12V 레일 ≈ 12V. **0V면 레일 끊김**(브레드보드 반쪽 문제)이거나 점퍼 빠짐, **−12V면 극성 반대**

## 5. 조립 · 시험 순서

한 번에 다 꽂지 말고 하나 붙일 때마다 시리얼로 확인한다.

1. **펌웨어 업로드** — Arduino IDE, 보드 *Arduino UNO R4 WiFi*, `control_panel.ino`. 시리얼 모니터 115200
2. **조명만** — USB 빼고 어댑터만 꽂아서(아두이노는 DC 잭 전원으로도 펌웨어가 돈다) 날씨·밥·안녕·보내기 4개가 켜지는지, 농담·질문은 잠갔을 때, INVERSE LED는 토글을 켰을 때 켜지는지. 냄새나 열이 나면 바로 뽑는다
3. **입력** — USB도 꽂고 3절 표의 시리얼 줄이 하나씩 다 찍히는지
4. **전체 상태** — 시리얼 모니터에 `?` 보내면 노브 3개 + 토글 3개 현재값이 한 번에 나온다
5. **화면** — 시리얼 모니터를 **닫고**(한 포트는 한 프로그램만) `npm run dev` → `output.html` → `panel ○`(Alt+S)로 포트 선택. 노브 돌리면 글자 크기가 바뀌어야 한다

### 마무리
- 납땜 자리·쓰지 않는 전선 끝(NC 등)은 **수축튜브/절연테이프** — 알루미늄 판에 닿으면 합선
- 아두이노·모듈은 판에서 띄워 고정(스페이서), 기판이 판에 직접 닿지 않게
- USB·어댑터 선은 당겨도 핀이 안 빠지게 한 번 묶는다
- 점퍼선은 전시 중 잘 빠진다 — 오래 걸면 R4용 스크류 터미널 쉴드로 바꾸는 걸 고려

## 6. 문제 해결

| 증상 | 원인 · 조치 |
| --- | --- |
| 조명이 하나도 안 켜짐 | 어댑터가 DC 잭에 안 꽂힘 / VIN 선 빠짐 / 12V가 브레드보드 **끊긴 반쪽**에 꽂힘 — 레일에서 12V 재 볼 것 |
| 버튼 하나만 조명 안 켜짐 | LED +/− 반대(두 선 바꾸기) 또는 커넥터 색을 잘못 고름(1·2가 아니라 NC에 연결) |
| 농담·질문 신호 안 들어옴 | 어댑터 빠짐 / 모듈 **입력 쪽 G** 빠짐 / C·NO 선이 바뀜(모듈 빨간 LED가 안 켜지면 입력 쪽 문제) |
| 농담 잠갔는데 `tog joke 0` | 모듈 출력 극성 문제 — 펌웨어에서 한 줄 뒤집으면 된다 |
| 누를 때가 아니라 뗄 때 찍힘 / 안 눌러도 계속 찍힘 | NO 대신 **NC**에 연결됨 |
| 다른 버튼 이름이 찍힘 | 선을 바꾸거나 `control_panel.ino` `sws[]`의 핀 번호를 바꾼다 |
| 노브 값이 0.5 근처에서만 움직임 | 와이퍼를 잘못 고름 |
| 노브 방향이 반대 | 양 끝 두 선(5V·GND) 바꾸기 |
| 토글·슬라이더 출력이 늦다가 **한꺼번에** 나옴 | ① 안 만져도 `knob …`이 계속 쏟아지면: 연결 안 된 A핀이 떠 있거나 가변저항 5V/GND가 헐거움 → 3개 다 단단히 연결. 그래도 흔들리면 펌웨어 쪽 흔들림 폭·전송 간격 조정 필요 ② 조용하다가 몰려 나오면: IDE 시리얼 모니터 지연(R4 WiFi는 USB가 ESP32를 거친다) — `output.html`(Web Serial)에선 문제 없음 |
| 평소에 조명이 꺼져 있음 (어댑터 꽂힘) | 새 펌웨어가 안 올라감 / ULN 보드 − 가 GND에 안 붙음 |
| 눌러도 안 꺼짐 | LED −가 아직 GND WAGO에 남아 있음(ULN 출력으로 옮겨야 한다) |
| 누른 것과 다른 버튼이 꺼짐 | `sws[]`의 led 핀 번호를 서로 바꾼다 |
| R4의 은색 칩(ESP32-S3 모듈)이 미지근함 | 정상 — USB 통신까지 맡아 늘 돈다. 손가락을 3초 못 댈 만큼 뜨겁거나 냄새·재시작이 있으면 전원부터 뺀다. ULN2003·포토커플러 모듈은 거의 차가워야 정상 |
| `output.html`에서 패널이 안 붙음 | IDE 시리얼 모니터가 포트를 잡고 있음 → 닫기. control.html 시험 연결과도 동시에 못 연다(`?serial=0`) |

## 7. 조명 제어 — 누르는 동안만 꺼짐 (ULN2003)

**평소엔 켜져 있고 누르는 동안만 꺼진다**(`LED_HOLD = true`, `LED_HOLD_IDLE_ON = true`, 2026-11-09). `LED_HOLD_IDLE_ON = false`면 반대(평소 꺼짐, 누르는 동안 켜짐). 아두이노 혼자 하므로 화면·페이지와 상관없다.
`LED_HOLD = false`로 두면 예전 깜빡임 방식 — 평소 켜짐, 누르면 `FLASH_MS`(80ms) 간격으로 `FLASH_N`(3)번 깜빡(`LED_IDLE_ON`=false면 평소 꺼짐).

- 대상: 날씨·밥·안녕·보내기 4개. **농담·질문 링은 제어 못 한다**(LED가 스위치 NO에 붙어 있어 잠기면 켜지는 구조), INVERSE LED도 토글 배선 그대로
- 원리: LED +는 계속 12V, LED −를 GND 대신 ULN2003 출력에 꽂는다. 아두이노 핀 HIGH → ULN이 그 출력을 GND로 당김 → 켜짐. **아두이노 핀엔 12V가 안 닿는다**

```
아두이노 D9  ── IN1      OUT1 ── 밥 LED −
         D10 ── IN2      OUT2 ── 날씨 LED −
         D11 ── IN3      OUT3 ── 안녕 LED −
         D12 ── IN4      OUT4 ── 보내기 램프 −
ULN 보드 −  ── GND 줄    ULN 보드 + ── 12V 줄   (전원 점퍼는 꽂힌 그대로)
```

- 출력은 보드의 흰 5핀 모터 커넥터에서 나온다. 28BYJ 케이블 기준 **파랑 = OUT4, 분홍 = OUT3, 노랑 = OUT2, 주황 = OUT1, 빨강 = +(12V, 안 씀)** — 보드마다 다를 수 있으니 시험으로 확인
- 버튼의 노랑·검정 중 **LED −인 쪽**은 🔊로 버튼 `1`/`2` 단자와 맞춰 찾는다(C 쪽을 옮기면 버튼 신호가 끊긴다)
- **시험**: 업로드 후 어댑터 + USB → 4개 다 켜져 있어야 한다. 버튼을 누르는 동안 **그 버튼이** 꺼지고, 보드의 작은 LED(A~D)도 같이 꺼진다. 다른 버튼이 꺼지면 선을 바꾸지 말고 `sws[]`의 네 번째 값(led 핀)을 바꾼다
- ULN2003 보드가 없으면: NPN 트랜지스터(2N2222·BC547) 4개 — 베이스 ← 1kΩ ← D핀, 이미터 → GND, 컬렉터 → LED −
- 포토커플러 모듈 남는 채널(3·4)로도 2개까진 된다 — 4개라 ULN2003으로 했다
- **색은 못 바꾼다** — 지금 버튼은 단색 LED(단자 2개). 바꾸려면 RGB 버튼(공통 양극 12V — 이 배선 방식을 그대로 이어 씀, 버튼당 3채널 → ULN2803 등) 또는 아케이드는 투명 캡 + WS2812. 2026-11-09 검토만, 미정

## 9. iPad 다이얼

패널의 원형 구멍 뒤에 iPad를 **가로로** 넣고 `src/dev/dial.html`을 띄운다. 다이얼은 보내기만 한다 — 돌리면 허브로 `{t:'receiver', name}` → `output.html`이 화면을 바꾸고 턴테이블에 이름을 보낸다. 맥에서 receiver가 바뀌어도 iPad 판 모양은 따라오지 않는다(마지막으로 돌린 쪽이 이긴다).

### 맥 쪽 — LAN 으로 띄우기

```
npm run dev:lan       # 기본 npm run dev 는 localhost 만이라 iPad 가 못 붙는다
npm run bridge:lan    # 허브도 LAN 용. 다이얼 메시지는 반드시 허브를 거친다
ipconfig getifaddr en0   # 맥 IP
```

- 작품은 인터넷이 필요 없다(Ollama·폰트·이미지 전부 로컬) — **전용 공유기**(인터넷 선 없이 전원만)에 맥과 iPad만 붙이는 게 제일 안전하다
- **학교 와이파이처럼 남과 같이 쓰는 망이면 iPad 주소만 받게** 띄운다 (`src/dev/allow-ip.mjs`):
  ```
  ALLOW_IP=<iPad IP> npm run dev:lan
  ALLOW_IP=<iPad IP> npm run bridge:lan
  ```
  - iPad IP: 설정 → Wi-Fi → 붙은 망 (i) → IP 주소. 같은 화면에서 **비공개 Wi-Fi 주소 끄기** — 켜져 있으면 주소가 바뀔 수 있다
  - 이 맥(localhost)은 항상 받는다. 그 밖의 주소는 페이지는 403, 허브는 연결을 끊는다(허브 로그에 `× 거부`)
  - 여러 대면 쉼표: `ALLOW_IP=a,b`. iPad IP가 바뀌면 두 서버를 새 값으로 다시 띄운다
  - 학교 와이파이가 기기끼리 통신을 막아 두면(흔하다) 이걸로도 안 붙는다 — 그땐 전용 공유기
- 모니터의 `output.html`은 계속 `localhost`로 연다(Ollama·Web Serial·웹캠이 localhost를 요구)
- iPad 주소: `http://<맥 IP>:5173/asemic/src/dev/dial.html`
- 오른쪽 아래 `bridge` 글씨가 초록이면 허브에 붙은 것 (패널에 가려 안 보일 수 있다)

### iPad 쪽 — 전체화면 고정

1. iPad 크롬/사파리 탭에선 주소창을 못 숨긴다 → 공유 버튼 → **홈 화면에 추가** → 그 아이콘으로 연다. 주소창 없이 상태 막대 밑까지 그림이 깔린다
   - `dial.html`의 홈 화면 설정(meta)을 바꿨으면 **아이콘을 지우고 다시 추가**한다 — 추가하는 순간의 값이 저장된다
2. 설정 → 디스플레이 및 밝기 → **자동 잠금: 안 함**
3. 설정 → 손쉬운 사용 → **사용 시간 제한(Guided Access)** 켜기 → 다이얼 앱 안에서 측면 버튼 3번 → 시작. 관람객이 쓸어서 빠져나가지 못한다
4. 충전기를 꽂아 둔다

dev 서버(`dev:lan`)로 띄운 동안은 맥에서 `dial.html`을 저장하면 iPad가 저절로 새로고침된다 — 위치 조정할 때 iPad를 뺄 필요 없다.

### 구멍에 위치 맞추기

`dial.html` 맨 위 `:root`의 세 값만 고친다 (현재 값은 파일을 볼 것):

| 값 | 의미 |
| --- | --- |
| `--dial-x` | 다이얼 한 변 대비 비율. − 왼쪽 / + 오른쪽 |
| `--dial-y` | − 위 / + 아래 |
| `--dial-scale` | 크기 배율. 판 테두리가 구멍보다 작아 검은 띠가 보이면 올린다 |

- 터치 판정은 화면에 그려진 위치를 따라가므로 따로 맞출 것 없다
- iPad 기종이나 거치 위치가 바뀌면 다시 맞춘다. 구멍 정면에서 사진을 찍어 비교하면 빠르다

### 화면 맨 위 그라데이션

iPad가 화면 맨 위(상태 막대 밑)를 **페이지 배경색**으로 물들인다. 다이얼 캔버스는 투명이라 배경이 검정이면, 다이얼을 돌려도 같은 자리에 남는 어두운 그라데이션이 구멍 위쪽에 보인다. 그래서 `html, body`의 `background`를 밝은 색으로 바꿨다 — 다시 검정으로 돌리지 말 것. (`theme-color` meta도 같은 이유)

### 패널에 끼운 채 작업하기

- **테스트만 할 때**: 맥 크롬에서 `http://localhost:5173/asemic/src/dev/dial.html`을 연다 — 마우스로 끌어 돌리면 iPad 다이얼과 똑같은 메시지가 나간다
- **iPad 화면을 맥에서 보기**:
  - 무선: iPad 제어 센터 → 화면 미러링 → 이 맥 (맥 설정 → 일반 → AirDrop 및 Handoff → AirPlay 수신 모드 켜기)
  - 유선: QuickTime → 새로운 동영상 녹화 → 녹화 버튼 옆 ⌄ → 카메라에서 iPad. **안 보이면** 케이블이 충전 전용이거나 허브·연장선을 거친 것 — 맥에 직접, 데이터 케이블로. iPad 잠금 풀고 "이 컴퓨터 신뢰" → QuickTime을 다시 연다. 맥이 iPad를 보는지는 `system_profiler SPUSBDataType | grep -i ipad`
- **맥 마우스로 iPad 조작**: 유니버설 컨트롤(맥 설정 → 디스플레이 → 고급) — 커서를 화면 끝 밖으로 밀면 iPad로 넘어간다. 미러링 화면을 보면서 움직인다
- 사이드카(확장 디스플레이)는 다이얼로 쓰지 말 것 — 손가락으로는 클릭·드래그가 안 된다(Apple Pencil만)

### 문제 해결

| 증상 | 확인 |
| --- | --- |
| iPad에서 페이지가 안 열림 | `dev:lan`으로 띄웠나, 같은 와이파이인가, 맥 IP가 바뀌었나, `ALLOW_IP`가 지금 iPad IP와 같은가(`forbidden`이 뜨면 이것) |
| 다이얼을 돌려도 화면이 안 바뀜 | `bridge:lan`으로 띄웠나, `bridge` 글씨가 초록인가. 모니터 `output.html` 주소에 `?bridge=ws://…`가 붙어 있으면 지울 것 |
| 위아래가 잘림 | 홈 화면 아이콘으로 열었나. 탭에서 연 거면 주소창만큼 잘린다 |
| 다이얼이 구멍에서 벗어남 | `--dial-x/y/scale` |
