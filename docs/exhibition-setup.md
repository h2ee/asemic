# 전시 환경 세팅 매뉴얼

전시장에서 처음 설치할 때, 그리고 매일 켜고 끌 때 보는 문서. 위에서부터 순서대로 하면 된다.
하드웨어를 분해·재조립하거나 배선 문제가 생겼을 때는 각 장치 문서를 본다:
[컨트롤 패널](../arduino/control_panel/installation.md) · [턴테이블](../arduino/turntable/installation.md)

---

## 0. 전체 그림

```
              ┌─────────── 전용 공유기 (MERCUSYS_A658, 인터넷 선 없음) ───────────┐
              │                                                                   │
   iPad (다이얼) ── Wi-Fi ──▶ 맥:5173 (dial.html)                                  │
                └─ Wi-Fi ──▶ 맥:9980 (bridge 허브) ──▶ output.html                 │
              └───────────────────────────────────────────────────────────────────┘

   맥 ── USB ──▶ 컨트롤 패널 (Uno R4 WiFi)   ┐
      └─ USB ──▶ 턴테이블 (Uno R3)           ├ output.html 이 Web Serial 로 직접 연다
      └─ 웹캠 / 스피커 / 모니터               ┘
      └─ Ollama (gemma3:12b) — 수신자 대답. 맥 안에서만 돈다
```

- **작품은 인터넷이 필요 없다.** LLM·폰트·이미지 전부 맥 안에 있다
- **학교·전시장 와이파이는 쓰지 않는다** — 기기끼리 통신을 막아 둔 경우가 많다(2026-11-09 SKKU 와이파이에서 확인: iPad → 맥 연결이 아예 안 닿음). 그래서 전용 공유기에 맥과 iPad만 붙인다
- 화면은 `output.html` 한 장이 전부 그린다. iPad 다이얼·허브가 없어도 키보드만으로 전시는 돈다

## 1. 처음 한 번만 하는 설정

### 1-1. 공유기

1. 공유기에 전원만 꽂는다(인터넷 선 필요 없음). Wi-Fi 이름·비밀번호는 공유기 바닥 스티커
2. 맥과 iPad를 **메인 Wi-Fi**에 붙인다. 게스트 Wi-Fi는 기기끼리 통신을 막아 두므로 쓰지 않는다
3. **두 기기의 IP를 고정한다** — 공유기 관리 페이지(브라우저에서 `http://192.168.1.1`)
   → DHCP / 주소 예약(Address Reservation) 메뉴에서 맥과 iPad를 지금 주소로 예약
   - 2026-11-10 기준: **맥 `192.168.1.100`, iPad `192.168.1.101`**
   - 맥 IP가 바뀌면 iPad 홈 화면 아이콘(주소가 저장돼 있음)이 안 열리고, iPad IP가 바뀌면 `ALLOW_IP`에 걸려 `forbidden`이 뜬다 — 예약해 두면 둘 다 안 생긴다
4. iPad: 설정 → Wi-Fi → 공유기 망 ⓘ → **비공개 Wi-Fi 주소: 고정(Fixed) 또는 끔** — "순환"이면 MAC이 바뀌어 예약이 안 먹는다

> 확인: 맥 터미널에서 `ipconfig getifaddr en0` → `192.168.1.100`

### 1-2. 맥

- **잠자기 끄기**: 시스템 설정 → 잠금 화면 → "디스플레이가 비활성 상태일 때 끄기: 안 함", 에너지 → "디스플레이가 꺼져 있을 때 자동으로 잠자지 않기" 켜기
- **알림 끄기**: 제어 센터 → 집중 모드 → 방해 금지(전시 화면 위로 알림이 뜨지 않게)
- **포커스 뺏기 막기** (2026-11-13 — 가끔 다른 창이 앞에 나와 키가 크롬으로 안 갔다):
  - 터미널 탭 하나에서 `npm run keepfront` — 2초마다 맨 앞 앱을 보고 크롬이 아니면 크롬을 다시 앞으로. 끼어든 앱 이름이 `logs/focus-<날짜>.log`에 남으니 범인을 찾으면 그 앱을 끈다. 터미널·시스템 설정이 앞일 땐 가만히 있다(끄기는 그 탭에서 Ctrl+C)
  - 흔한 범인: iPad를 USB로 꽂으면 **사진/이미지 캡처**가 열림(이미지 캡처 앱 → iPad 선택 → "이 iPad를 연결하면: 응용 프로그램 없음"), **Creative Cloud**·소프트웨어 업데이트 알림(종료), 블루투스 스피커 연결 창
  - **파란 입력 소스 표시기** (2026-11-14 — 크롬은 맨 앞인데 키가 안 들어가고 커서 옆에 파란 한/영 표시가 떠 있었다, 클릭하면 풀림. keepfront로는 못 잡는다): 터미널에서 `defaults write kCFPreferencesAnyApplication TSMLanguageIndicatorEnabled -bool false` → 로그아웃·재로그인. 한/영 전환은 그대로 되고 표시만 안 뜬다(되돌리기 `-bool true`). macOS 26에서 먹히는지는 한/영을 눌러 확인
- **방화벽**: 켜 둬도 된다. 처음 `npm run dev:lan`을 띄울 때 "node 수신 연결 허용?"이 뜨면 **허용**
- **Ollama 모델 확인**: `ollama list`에 `gemma3:12b`가 있어야 한다. 없으면 인터넷 되는 곳에서 미리 `ollama pull gemma3:12b`(8GB) — 전시장 공유기엔 인터넷이 없다
- **소리 출력 장치**: 시스템 설정 → 사운드 → 출력 → 턴테이블 밑 스피커. 브라우저는 OS 기본 출력으로 낸다

### 1-3. iPad (다이얼)

1. 맥에서 서버를 띄운 상태(2절)로 iPad 사파리에서 `http://192.168.1.100:5173/asemic/src/dev/dial.html`
2. 공유 버튼 → **홈 화면에 추가** → 이후로는 그 아이콘으로 연다(주소창 없이 전체화면)
3. 설정 → 디스플레이 및 밝기 → **자동 잠금: 안 함**
4. 설정 → 손쉬운 사용 → **사용 시간 제한(Guided Access)** 켜기 + 암호 설정
5. 다이얼 위치(구멍에 맞추기)는 [패널 문서 9절](../arduino/control_panel/installation.md#9-ipad-다이얼)

### 1-4. 패널·턴테이블 포트 고르기

`output.html`을 처음 열었을 때 한 번만(3-2에서). 그 뒤로는 새로고침·USB 재연결 때 저절로 붙는다.

## 2. 매일 켜기

### 2-1. 하드웨어 전원

| 순서 | 장치 | 할 일 |
| --- | --- | --- |
| 1 | 공유기 | 전원 |
| 2 | 턴테이블 | **USB 먼저 → 12V** (반대로 하면 드라이버가 엉뚱하게 움직일 수 있다) |
| 3 | 컨트롤 패널 | USB + **12V 어댑터** (어댑터가 빠지면 농담·질문 버튼·버튼 조명이 안 된다) |
| 4 | 웹캠·스피커·모니터 | 맥에 연결 |
| 5 | 맥·iPad | 둘 다 공유기 Wi-Fi(`MERCUSYS_A658`)에 붙었는지 확인 |

### 2-2. 맥 — 터미널 세 개

**터미널 ① — LLM**
```
ollama serve
```
(Ollama 앱이 메뉴 막대에 떠 있으면 이미 돌고 있는 것 — 건너뛴다. "address already in use"가 나와도 이미 돌고 있다는 뜻)

**터미널 ② — 화면 서버**
```
cd ~/asemic
ALLOW_IP=192.168.1.101 npm run dev:lan
```
`ALLOW_IP: 이 맥 + 192.168.1.101`과 `Network: http://192.168.1.100:5173/asemic/`이 찍히면 정상

**터미널 ③ — 다이얼 허브**
```
cd ~/asemic
ALLOW_IP=192.168.1.101 npm run bridge:lan
```
`ws://192.168.1.100:9980 (LAN)`과 `ALLOW_IP: 이 맥 + 192.168.1.101`이 찍히면 정상

> - `ALLOW_IP`는 iPad 주소. 이 맥(localhost)은 항상 받고, 그 밖의 주소는 막는다(`src/dev/allow-ip.mjs`). 전용 공유기라 없어도 되지만 붙여 두는 게 안전하다
> - 터미널 창은 전시 내내 열어 둔다. 닫으면 서버가 꺼진다
> - 맥 IP를 확인할 땐 `ipconfig getifaddr en0`

### 2-3. 맥 — 전시 화면

1. **크롬**에서 `http://localhost:5173/asemic/src/dev/output.html` — **반드시 `localhost`로**
   - `192.168.1.100:5173`으로 열면 `forbidden`이 뜬다(ALLOW_IP는 이 맥을 루프백 주소로만 알아본다). 웹캠·Web Serial·Ollama도 localhost에서만 된다
   - 주소 뒤에 `?bridge=ws://…`가 붙어 있으면 지운다(예전 북마크) — 다이얼이 안 먹는다
2. 웹캠 권한을 물으면 **허용**
3. 처음 한 번만: 오른쪽 위 `panel ○ table ○` 버튼(또는 **Alt+S**) → 포트 선택. 보드가 둘이면 두 번
   - Arduino IDE 시리얼 모니터가 열려 있으면 포트를 못 잡는다 — 닫는다
   - 둘 다 붙으면 버튼이 흐려진다
4. 턴테이블이 호밍(약 20초, 한 바퀴)한 뒤 지금 receiver 자리로 간다
5. 전체화면: **⌃⌘F** (크롬 메뉴 보기 → 전체 화면). 마우스 커서는 화면 밖으로
6. 아무 키나 한 번 눌러 소리를 푼다(브라우저는 첫 입력 전엔 소리를 안 낸다)

### 2-4. iPad

1. 홈 화면의 다이얼 아이콘으로 연다
2. 오른쪽 아래 **`bridge` 글씨가 초록**인지 확인(패널에 가려져 있으면 끼우기 전에)
3. 측면 버튼 3번 → 사용 시간 제한 시작
4. 충전기 연결

## 3. 켜고 나서 점검 (5분)

- [ ] 키보드로 한글을 치면 글자가 자라고 소리가 난다
- [ ] Enter → 잠시 뒤 말풍선이 떠오르고 수신자가 한국어로 대답한다 (안 오면 Ollama — 터미널 ①)
- [ ] 노브(크기·자간·행간)를 돌리면 글자가 바뀐다
- [ ] 버튼(날씨·밥·안녕·보내기)·토글(농담·질문·INVERSE)이 먹는다, 버튼 조명이 켜져 있다
- [ ] iPad 다이얼을 돌리면 화면 receiver가 바뀌고 **턴테이블이 그 사물로 돈다**
- [ ] 웹캠이 오른쪽 위 프로필에 나온다
- [ ] 스피커로 소리가 나온다
- [ ] 터미널 ③ 허브 로그에 `× 거부`가 없다(있으면 iPad IP가 바뀐 것)

## 5. 문제 해결

| 증상 | 확인 |
| --- | --- |
| iPad에서 `forbidden` | iPad IP가 `ALLOW_IP`와 다르다 → iPad IP 확인 후 터미널 ②③을 Ctrl+C하고 새 IP로 다시 띄움. 공유기 주소 예약(1-1) |
| 맥 크롬에서 `forbidden` | `localhost` 대신 `192.168.1.100`으로 열었다 → localhost로 |
| iPad에서 "사이트에 연결할 수 없음" | ① 맥·iPad가 같은 공유기 Wi-Fi인가(학교 Wi-Fi면 안 된다) ② 맥 IP가 `192.168.1.100`인가 ③ 터미널 ②가 `dev:lan`으로 떠 있나(`npm run dev`면 localhost만) |
| 다이얼은 뜨는데 `bridge 연결 안 됨` | 터미널 ③이 `bridge:lan`으로 떠 있나. 허브 로그에 `× 거부`가 있으면 ALLOW_IP |
| 다이얼을 돌려도 화면이 안 바뀜 | output.html 주소에 `?bridge=`가 붙어 있나 / 터미널 ③이 꺼졌나 / localhost 전용 허브가 따로 떠 있나(`lsof -nP -iTCP:9980 -sTCP:LISTEN`에 줄이 둘이면 하나를 끈다) |
| 수신자가 대답을 안 함 | Ollama가 안 돌고 있다 → 터미널 ①. 첫 대답은 모델 로딩으로 수십 초 걸릴 수 있다 |
| 소리가 안 남 | 키를 한 번 눌렀나 / macOS 출력 장치 / 크롬 탭 음소거 |
| 웹캠이 빈 원 | 크롬 권한(주소창 왼쪽 아이콘) / localhost로 열었나 / `?cam=0`이 붙었나 |
| 패널·턴테이블이 안 붙음 | Arduino IDE 시리얼 모니터 닫기 → Alt+S로 다시 선택. 자세한 건 각 장치 문서 문제 해결 절 |
| 턴테이블 `home_fail` / `lost` | [턴테이블 문서 7절](../arduino/turntable/installation.md#7-문제-해결) |
| 농담·질문만 안 먹음 | 패널 12V 어댑터 |
| 화면이 이상해짐 | output.html 새로고침(⌘R) — 패널·턴테이블은 저절로 다시 붙고, 턴테이블은 다시 호밍한다 |

## 6. 개발할 때 (학교 Wi-Fi에서)

- Claude·인터넷을 쓰려면 맥을 학교 Wi-Fi로 옮겨야 한다. 이때 iPad는 맥에 못 붙는다(학교 망 격리) — 다이얼 시험은 맥 크롬에서 `http://localhost:5173/asemic/src/dev/dial.html`을 열고 마우스로 돌린다
- 서버(`dev:lan`/`bridge:lan`)는 Wi-Fi를 바꿔도 다시 띄울 필요 없다. 공유기로 돌아오면 iPad가 그대로 붙는다
- 학교 Wi-Fi에서 `dev:lan`을 띄워 둘 땐 반드시 `ALLOW_IP`를 붙인다 — 없으면 같은 망 누구나 소스와 허브에 붙을 수 있다
